Academic Standard Operating Procedure

Computer Engineering Department ML Project

A systematic 10-week machine learning project implementation for Loan Default Prediction.

Week 1

Problem Definition & Exploration

Problem formulation, business context, ingestion of 255,347 loan applications, data dictionary, class imbalance analysis (~88.4% non-default, ~11.6% default).

Week 2

Data Cleaning & Preprocessing

Zero missing values verified, IQR/Z-score outlier detection and winsorization, binary label encoding, one-hot dummy encoding, and StandardScaler normalizations.

Week 3

Model Creation (Library & Scratch)

Justification of tree-based models on tabular financial data. Scikit-learn Decision Tree baseline + custom pure Python/NumPy Decision Tree built without ML libraries.

Week 4

Model Evaluation & Overfitting Check

Precision, Recall, F1, ROC-AUC, Specificity, Confusion Matrix analysis. Tree depth sweep diagnosing high bias (underfitting) vs high variance (overfitting).

Week 5

Advanced Models & Hyperparameter Tuning

Random Forest, Gradient Boosting, 5-Fold Stratified Cross-Validation, GridSearchCV tuning of hyperparameters (n_estimators, max_depth, min_samples_split).

Week 6

Visualization of Metrics

Display of 7 distinct evaluation graph types: ROC curves, PR curves, Confusion Matrix heatmaps, Feature Importances, Learning curves, Calibration, and CV boxplots.

Week 7

Flask Project Setup

Production Flask modular application setup with configuration management, routes, and web forms.

Week 8

Frontend User Interface

Glassmorphic, responsive user interface with 16 input parameters, quick preset profiles (Low/Med/High risk), and visual risk gauge rendering.

Week 9

Backend & Free Hosting Deployment

REST API endpoints, Docker containerization, Procfile, Render deployment blueprint (render.yaml), and deployment guide.

Week 10

Final Project Evaluation

Comprehensive project evaluation notebook and report: financial cost matrix, decision threshold tuning, error analysis, and production roadmap.
